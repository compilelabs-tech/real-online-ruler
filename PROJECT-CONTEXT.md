## 8. 🌐 i18n Architecture Summary

### URL Structure: `/[locale]/` path-based
```
/ (redirects to /en/)
/en/ (English — default)
/es/ (Spanish)
/fr/ (French)
/de/ (German)
/pt/ (Portuguese)
/ja/ (Japanese)
/ko/ (Korean)
/zh/ (Chinese)
/hi/ (Hindi)
/ar/ (Arabic — RTL)
/ru/ (Russian)
/it/ (Italian)
/tr/ (Turkish)
/vi/ (Vietnamese)
/th/ (Thai)
```

### Hreflang Strategy
- Bidirectional hreflang for all 15 locales
- `x-default` pointing to `/en/`
- Self-referencing hreflang on every page
- Validate with Ahrefs/Screaming Frog

### Astro 5 i18n Config
```js
// astro.config.mjs
export default defineConfig({
  i18n: {
    defaultLocale: 'en',
    locales: ['en', 'es', 'fr', 'de', 'pt', 'ja', 'ko', 'zh', 'hi', 'ar', 'ru', 'it', 'tr', 'vi', 'th'],
    routing: {
      prefixDefaultLocale: false
    }
  }
});
```
