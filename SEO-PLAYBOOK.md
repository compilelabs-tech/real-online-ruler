## 3. Technical SEO Checklist

### Pre-Launch (Week 1)

- [ ] **Core Web Vitals**
  - [ ] LCP < 1.5s (optimize fonts, hero image)
  - [ ] FID < 100ms (minimize JS, defer non-critical)
  - [ ] CLS < 0.1 (set explicit dimensions for ruler)
  - [ ] TTI < 2.0s (code-split, lazy load below-fold)

- [ ] **Meta Tags (per language)**
  - [ ] Unique `<title>` tag (60 chars max)
  - [ ] Unique `<meta description>` (155 chars max)
  - [ ] Open Graph tags (og:title, og:description, og:image, og:locale)
  - [ ] Twitter Card tags
  - [ ] Canonical URL

- [ ] **Structured Data (JSON-LD)**
  ```json
  {
    "@context": "https://schema.org",
    "@type": "WebApplication",
    "name": "Online Ruler",
    "url": "https://realonlineruler.com/en/",
    "description": "Free online ruler to measure in cm, mm, and inches at actual size.",
    "applicationCategory": "UtilityApplication",
    "operatingSystem": "Any",
    "offers": {
      "@type": "Offer",
      "price": "0",
      "priceCurrency": "USD"
    },
    "inLanguage": ["en", "es", "fr", "de", "pt", "ja", "ko", "zh", "hi", "ar", "ru", "it", "tr", "vi", "th"]
  }
  ```

- [ ] **Hreflang Tags** (see README.md for full implementation)
  - [ ] 15 bidirectional hreflang links
  - [ ] x-default pointing to /en/
  - [ ] Self-referencing hreflang on every page

- [ ] **Sitemap**
  - [ ] Auto-generated XML sitemap
  - [ ] Include all 15 language variants

- [ ] **Robots.txt**

- [ ] **Security**
  - [ ] HTTPS enforced (Cloudflare auto-SSL)

### Ongoing Technical SEO

- [ ] Monthly Core Web Vitals audit
- [ ] Monthly broken link check
- [ ] Monthly hreflang validation (Ahrefs/Screaming Frog)

## 9. 🌐 Hreflang Validation Checklist

### Pre-Launch Validation
- [ ] All 15 languages have self-referencing hreflang
- [ ] x-default points to /en/
- [ ] Bidirectional hreflang (if /en/ links to /es/, /es/ links back to /en/)
- [ ] No orphan pages (every page linked from sitemap)
- [ ] Hreflang URLs are canonical (no redirects)

### Monthly Validation
- [ ] Run Screaming Frog hreflang report
- [ ] Check Google Search Console for hreflang errors
- [ ] Verify no orphan pages in each language
- [ ] Check for conflicting canonical tags
- [ ] Verify language switcher links match hreflang URLs

### Common Hreflang Errors to Avoid
- ❌ Missing return tags (A links to B, but B doesn't link back)
- ❌ Mismatched URLs (hreflang URL doesn't match canonical URL)
- ❌ Wrong language code (e.g., "pt" instead of "pt-BR")
- ❌ Missing x-default
- ❌ Using relative URLs instead of absolute URLs
